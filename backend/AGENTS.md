# API do TaxFlow (Laravel)

- **Ambiente:** tudo roda via Docker Compose, a partir da raiz do repositório. Não instale PHP nem Composer no host.
- **Comandos:**
  - `docker compose exec api php artisan <comando>`
  - `docker compose exec api composer <comando>`
  - Testes: `docker compose exec api php artisan test`
- **Mais detalhes:** setup, portas e observações estão no `README.md` da raiz.
